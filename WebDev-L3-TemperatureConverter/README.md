# 🌡 Premium Temperature Converter

A clean, animated temperature converter built with vanilla HTML, CSS, and JavaScript. Convert instantly between **Celsius**, **Fahrenheit**, and **Kelvin** through a glassmorphic interface with live visual feedback.

## ✨ Features

- **Three-way conversion** — Celsius ⇄ Fahrenheit ⇄ Kelvin, in either direction
- **Live thermal bar** — a fill bar inside the result box rises and shifts color (blue → mint → orange) to match the converted value
- **Animated result** — the headline number counts up/down to its new value instead of snapping instantly
- **One-tap swap** — flip the "From" and "To" units with an animated swap button
- **Instant conversion** — updates as you type, on unit change, or on Enter
- **Input validation** — rejects invalid input and values below absolute zero, shown inline with a subtle shake instead of a browser alert
- **Fully responsive** — adapts down to mobile screens
- **Accessible motion** — respects `prefers-reduced-motion`

## 🛠 Tech Stack

- HTML5
- CSS3 (custom properties, animations, glassmorphism)
- Vanilla JavaScript (no frameworks or libraries)
- [Poppins](https://fonts.google.com/specimen/Poppins) & [Space Mono](https://fonts.google.com/specimen/Space+Mono) via Google Fonts
