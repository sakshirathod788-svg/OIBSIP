# 🌡 Premium Temperature Converter

A modern, responsive **Temperature Converter** built using **HTML5, CSS3, and JavaScript**. Instantly convert temperatures between **Celsius (°C)**, **Fahrenheit (°F)**, and **Kelvin (K)** through a beautiful glassmorphism interface with smooth animations and live conversion.

## ✨ Features

- 🌡 Convert between Celsius, Fahrenheit, and Kelvin
- ⚡ Instant conversion while typing
- 🔄 One-click unit swap
- 📊 Displays values in all three units simultaneously
- 🎨 Modern Glassmorphism UI
- 📱 Fully Responsive Design
- 🎯 Accurate temperature calculations
- ⌨️ Press **Enter** to convert instantly
- 🚀 Smooth animations and hover effects
- 💻 Beginner-friendly clean code
